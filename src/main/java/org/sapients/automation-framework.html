✅ Automation Framework Architecture Explanation

1. Project Structure:

  • src/main/java
    • pages/ – Page classes (POM)
    • utils/ – Utility classes (e.g., ExcelUtils, ConfigReader)
  • src/test/java
    • tests/ – Test classes
    • listeners/ – TestNG Listeners (for logs, reports, screenshots)
  • resources/
    • config.properties – Configuration file
    • testdata/ – Excel or JSON test data
  • pom.xml – Maven dependencies
  • testng.xml – TestNG suite file

2. Key Components:

  • Page Object Model (POM): Encapsulates UI interactions in reusable page classes.
  • TestNG: Test execution framework (annotations, assertions, parallel run).
  • Maven: Build tool to manage dependencies and test execution.
  • Reporting: ExtentReports or Allure integrated via listeners.
  • Utilities: Reading configs, handling waits, taking screenshots.
  • CI Integration: Jenkins or GitHub Actions for scheduled/triggered test runs.
